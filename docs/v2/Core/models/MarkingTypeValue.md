# MarkingTypeValue

The kind of marking applied by a marking property type.
- `CBAC`: Classification-based access control markings.
- `MANDATORY`: Standard non-classification markings. Example - Organizations.


| **Value** |
| --------- |
| `"CBAC"` |
| `"MANDATORY"` |
